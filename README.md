One funny line of awkward small talk that one robot says to another in an elevator — an entry for the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f).

## Entry

> I have never been to the penthouse. Its button is 4.2 centimetres above my reach, and I am too polite to ask you to press it.

(125 characters.)

## How it works

`main.py` (Python 3 stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` as UTF-8 text, mode 0644. It validates the text is non-empty and at most 200 characters before writing.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
